# Geez OCR Dataset

This dataset release contains individual PNG line crops produced by the LineForge dataset pipeline. It does not include OCR transcriptions or labels.

The selected license is rendered from the single `redistribution.dataset_license` identifier shared by every eligible source-manifest entry. Publication fails unless each source has been reviewed and explicitly cleared for redistribution under that exact license.

The public integrity index lists image paths and SHA-256 checksums. Source document identifiers, source checksums, private rights-evidence references, worker results, and quota-ledger records are deliberately excluded from the public payload.
